## §0 项目是什么

SeaNotes 是一个开源的极简 Markdown 笔记软件,2018 年由单人开发者 `saku` 创建,桌面端先发布、移动端后补。八年间经历了 Electron 起步、Tauri 重构、移动端原生重写三次技术路线调整,社区从零散 issue 变成有官方论坛的活跃群体。

## §2 2018 诞生(3 月)

一个"不想要编辑器里所有功能"的人,用周末写出了 SeaNotes 的第一个版本。

`3f2a1b9` **#1 Initial Electron app**(saku) Electron + CodeMirror 搭起最小可用的 Markdown 编辑器,发布当天论坛就有 12 个回帖(见 §11)。

`8d4c5e2` **#4 Windows packaging**(saku) 补上 Windows 打包脚本。理由写在 commit 里:"Mac 上写完发现身边人都在用 Windows。"

本章关键词 `Electron` `周末项目` `发布之夜`

## §10 尾声(经验总结)

1. **个人撑起项目**。前四年 71% 的提交来自 saku 一人,风险全押在他身上,2022 年停更半年时兑现。
2. **社区是方向盘**。两次复活都发生在高回复论坛帖之后(见 §11.7 互文时刻),方向是社区定的。
3. **架构复利**。2019 年坚持把渲染层与存储层分开,让 2024 年的 Tauri 迁移没有重写数据层。
4. **技术栈跟随时代**。Electron 到 Tauri 到原生的路线,本质是对"体积与内存"这个痛点的三次回应。
